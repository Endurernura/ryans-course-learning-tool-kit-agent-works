# 可读性审查与改写

## 先辨认读者卡在哪里

每节先写出读者要弄明白的具体关系，再安排信息。解释稿把前因、措施和结果接起来。背诵稿写出题目问法、能落笔的答案及必要限定。两稿采用相同术语、分类和比较维度。

| 检查角度 | 常见症状 | 改写动作 |
| --- | --- | --- |
| 语言 | 电报式短语、主语省略、命题批注插入定义，反复使用“不能”“无法”“不可”提示错误 | 先写完整的正面陈述或可执行步骤。保留会改变答案的限制，并写明它约束的对象和条件 |
| 逻辑 | 两稿同一主题分类不一致，一节内从定义跳到旧题争议，因果链只有首尾 | 建立两稿共用的小节顺序和概念对应。补上说明结果所必需的原因、中间量或比较维度。把同一维度的内容放在一起 |
| 内容 | 提到某项知识、若干分项或一幅图，正文只出现其名称或指向原材料 | 先判定读者需要掌握的粒度，在当节补释义、分项、条件、关键图或替代说明。仅供拓展的内容可列可选查阅，标签要明确 |
| 组织 | 同一知识点在题型、旧编号和索引中来回出现，文中不断提示读另一份资料 | 正文按学习任务展开。题型用于检索或练习。按课件枚举的索引放在正文之后，同一知识的重复条目在同处汇总 |
| 页面 | 一句问法考几件事，数个答案合在一个段落；短答、索引和正文在页面上难以区分 | 按实际得分点拆题或分行，给问法、答法和同维度的比较对应的层级。读者一眼能看出哪里切换问题 |

## 区分两类限制句

- **会改变知识或答案的条件。** 试着暂时去掉，然后问结论、操作或判分会不会改变。会改变时就紧贴结论保留。比如把“不能使用不同单位”改写成“代入前统一量纲和单位”。术语定义或否定式原题需要保留否定时，写清谁在什么条件下受到限制。
- **校对过程或泛化提醒。** 例如连续说“不可将旧答案当作唯一口径”，却一直没有给出这门课的答法。正文先给当前课程可用的答法。旧答为何不一致放在题解或来源说明，并提供可选的定位。语言筛查用来找到这些句子，是否保留取决于句子承担的作用。

## 正文独立阅读检查

1. 遮住“出处”“回查”和另附的表。逐节问读者能否完成标题或题目承诺的任务。首次提到的概念给出名称及含义，分类和阶段给出实际成员及顺序，公式给出式子和符号说明。图表用于辨认时，给可读的图表或足以完成当前辨认的文字。独立成册的背诵稿也做这项检查。
2. 查“手记”“资料中”“如图”“见上”“详见”“某种”等提示，并从语境识别没有这些字样的缺项。每个必须理解的引用都追到确切对象，补进当前节或加明确可达的文内定位。真正只供扩展的引用集中放入索引。注明来源不能替代写全知识。
3. 逐项判断有疑问的材料能否使用。核实后给出具体内容。暂时不能证实且影响答案时，说明能确定的部分及尚缺什么。诸如底稿待核编号、文档版本比较、去重步骤和数据来源迁移，保留在底稿或附录。
4. 看每个长段是否同时解释两类以上的问题。可依次写成“是什么”“为什么”“怎样用”或用对照表。背诵稿优先用短答案、分点或同维度短表，保持自然句和必要解释。
5. 遇到教材标题、课件页码或笔记名称开头的句子，先写出该处真正需要理解的对象和结论。若例子有分析作用，交代与结论相关的场景、问题和处理方法，具体名称无法核实时可用准确的场景描述。同一节的常规回查集中处理，题型来源仍按用户要求随题保留。

## 内部迭代怎么做

1. **对着原稿读。** 选一处曾被反馈难读的段落，再选一处术语密集、计算、图表或旧题口径冲突处。顺读时只允许使用本节已出现的内容。记下首次卡住的原句，以及读者必须猜测、回读或跳走才能获得什么。
2. **按功能标句。** 标出定义、前提、原因、过程、结果、答法和出处。先修正主题层级和叙述顺序，再补缺失的推理或答题材料，最后精简重复提示。不要用全局删词代替审阅。
3. **拿同一题验证两稿。** 从全套稿找概念与推导，合上后尝试用背诵稿要点复述。比较术语、分类、适用条件与答案方向。若需跳转，确认跳过去是为了查证或扩展，能完成当前作答的内容留在本节。
4. **扩大到同类问题。** 搜索“不能”“无法”“不可”、旧答案口吻和跳转提示，打开所在段核对每处作用。遇到缩写先区分简明俗称和专业简称，按全稿首次出现核对全称与含义。跨章节重复分类时对照对象、层级和适用场景。检查关键公式及图表的阅读顺序。命中次数只作排查线索，不设机械删词目标。
5. **用最终成品复读。** 从原卡点再走一遍。读者能说出该节的对象、条件和结论，能写出完整答案，并能选择性查证时，再检查导出版中的目录、页行、图片文字和定位。记录仍缺证据的具体项目。
