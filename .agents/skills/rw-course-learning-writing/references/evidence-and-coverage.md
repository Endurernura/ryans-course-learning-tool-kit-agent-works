# 来源核对与考点查漏

## 归档和底稿

1. 先从本项目说明、课程索引和已确认别名定位目录，再按需查找未归档资料。收到多个转写包时查看成员和时间范围，并核对是否另有原音。微信材料还可能在合并转发附件里。
2. 用授课主题、时间及课件内容交叉判断归属。内容过短或多门共用时记录待确认项和上下文。对已确认单独保存的实习，按项目规则归档，并按已有约定处理其考核范围。
3. 同名文件用版本、页数和内容辨认。需要判断是否为同一字节版本时核对 SHA-256。记录归档副本和来源。转成 PDF 或文本时核对页数和顺序。只在本轮取得授权的范围内移动或清理实体文件。
4. 登记录音 ID、时间范围、原音可用情况，以及课件题名与版本。幻灯片号、PDF 文件页、纸面印刷页和重点合集页各用明确的标记。扫描件、图表和公式遇到文字层为空或错序时，打开原页图核对。
5. 用于后续查证的工作底稿优先做到可检索，保留相关文件、准确时间戳、页码和待核项。需要交给下一轮的资料包须含清单，列明来源、版本和位置。打包完成后回读成员及路径，按需核对源文件与包内副本的哈希。

## 录音校订和引用

| 要确定的事项 | 核对依据 |
| --- | --- |
| 老师实际讲了什么，是否说会考 | 用能辨认的原音与前后语境核对，保留录音 ID 和时间。当前任务中用户对老师原话的明确确认，也可登记为依据 |
| 概念、专业词、公式、图示、操作顺序 | 查对应版本与页码的原授课件、重点合集及课程指定资料。需要替代资料时明示身份与支持的范围 |
| 往年题的题干、题型、数据、图表 | 回到原卷。答案版用于定位或交叉核对，计算重新代入原题条件独立验证 |
| 手写读法或学生记录 | 放大原图核对字形、同字写法和上下文。疑字逐项编号，保存原图定位，采纳用户明确确认的读法 |

- 先按日期、文件名和录音 ID 查原音，并确认转写和原音是否同一段。有原音时优先回查会影响结论的短窗，保留前后句。可用本地工具二次识别。使用裁剪片段时，将所得时间戳按起点换回原录音时间。
- 优先核查否定词、语气词、专业简称、主体和比较方向、数字、单位、公式符号以及评分和考试范围。两次机器识别一致只能作为定位线索。教师的明确判断仍需要清楚的语境，数学结论仍需独立核对。
- 表中以校订摘要为默认阅读列。原机器文本另列，并标注其识别状态。无法回听时用现存转写上下文和课件校订内容，注明证据只到这一层。课件能支持概念或定义时写入摘要。教师是否强调过该点依录音或明确确认判断。
- 原文或转写的否定范围仍含混时，保留知识点并将题型或范围列为待核。只有实际存在的原音才列为可回听。摘要可补足课件支撑的定义或步骤，并标明补足来自哪一页。

## 提取与双向查漏

1. **顺着课堂找知识点。** 逐段读前后文，按主题与操作环节切分。检索“必考”“可能”“判断”“填空”“给表”“画图”等词及常见误识别只能定位候选。逐个打开上下文，也检查没有命中词的讲解、例题收尾、正反例和复习段。
2. **从材料反查课堂。** 按章节对照重点标记、划线内容、图表、近似概念辨析和原卷题型，找出转写跳段、误名及只有课件证据的内容。重点合集可作入口，细节或定义有疑问时回到分章原页。
3. **把性质写清。** 区分正式考试通知、教师明确提示、可能的考查形式、往年曾考、课堂例题或普通讲解、课件补充、尚待确认。知识命题与考查表述分别登记。有用的材料补充可以出题，以材料为依据。
4. **按知识点查题、按题查知识点。** 每道题能定位到支持它的来源。对明确提示、重点计算、重点图表和用户指定主题，标明是否已有足够练习。多道题考到同一主题时，看它们是否覆盖了不同的误区或能力。没有题的条目依交付范围处理，保留覆盖缺口。
5. **优先找容易被漏掉的细节。** 查比较对象、例外或前提、阶段顺序、条件改变后的结果、公式分母和单位、图中容易忽略的层次与标注。将一句“看懂了”拆为可判定的命题，必要时用一道短题验证。

可复用的考点表列顺序为 `条目编号 | 主题 | 校订摘要 | 考查性质 | 课程与版本 | 录音 ID 和时间 | 原课件/合集/原卷定位 | 校核方式及疑点 | 对应题号 | 机器原文（留档）`。各来源只填有证据的字段，按当前交付需要选用。

例如，转写能辨认出老师在比较两种材料，专业术语由课件校正后可写进知识摘要。若只有一版识别到“可能做判断”，可暂记为“可能考判断”，并保留该线索的时间与校核情况。
