# 材料写作与成稿验收

## 选择与任务对应的成品

| 成品 | 组织方式与交付重点 |
| --- | --- |
| 写作方法与资料包 | 按章给读者难点、叙述顺序、拟采用的录音与课件页、需要保留的图表和可执行验收项。涉及疑词时附校订对照。用户只要求方法时，到此交付 |
| 来源对照或课程笔记 | 对照底稿以时间、页码和检索为主。个人笔记优先保留已定的顺序、密度和说法，补关键遗漏或辨析。新增解释与原记录分别注明 |
| 阅读材料 | 先说本节要解决的课程问题，再解释术语、前提、过程和结果。用合适图表呈现关系，用例题检验理解。按课程主线重排 PPT，保留有解释价值的重点标记和图表 |
| 背诵材料 | 按主题和题型给可复述、可落笔的要点。可用定义、对照、分点标准答法和计算步骤。承接阅读材料中的术语，保留用户要求的定位 |
| 全量复习稿 | 每章按理解、背诵、应用的顺序。理解段保留主线及关键图表。背诵段按题型组织。应用段把题目与答案、知识点互相定位。覆盖要求落实到章节、知识点和考查形式 |
| 练习题库 | 先核定题型及覆盖要求，再出题。混合安排细点判断、易混选项和整块知识的应用。题干和解析均标来源，答案与作答区按约定组织。电子重复练习按需提供随机顺序、换值及错题重练 |

## 写作方法

- 每节先回答一个具体问题。先说明什么对象、在什么条件下、要解决什么问题，再解释过程与现象。比较题使用同一组比较维度，例如主体、方向、步骤或结果。步骤按执行顺序写，因果要明示中间环节。内容难以承接时补一个具体前提或例子。阅读材料里提到需要辨认或解释的关键图表时，把图或有依据重绘的关系图与解释放在一起，确认图中能找到正文点明的要素。
- 首次出现有必要识别的英文简称时给中文名、英文全称和简称。公式和图表旁解释变量、单位、取值方向及适用条件。阅读入口独立的章节或随机题可配就近的术语提示。
- 正文以知识和操作为主。开头可给必要的学习顺序，题型、复习范围或使用方法只有影响读法时才写。来源、版本与核对说明放边注、节末或独立来源表。知识的适用条件写在结论旁。读者能按作者给出的主题学完一节，再去核对出处。
- 根据用户要求的证据范围给题干和解析标出处。可使用“课上／材料／历史”这样的来源标签，并带时间、页码或题号。原题据原卷逐字核对，仿题、同构题和新题用清楚的标签。若用户只要往年题，按原卷组题，缺某章节或题型时据实记录。
- 简答先给完整问法，再按可得分的角度分点写标准答法。优先查题目出处给出的答案。出处缺答法时，定位到对应课程页再组织。修订补充时保留用户指定的原提纲或正文。
- 计算题先辨认所求和原始条件，再按公式代入、列出关键中间量并复核，特别检查分母、单位和正负号。用新数值出变式时逐题验算，并检查题意、答案和选项仍一致。
- 电子版若重排选项，用稳定题号与选项身份判分。二次练习可随机题序、选项及同构数值，并测试答对、答错、错题重练和答案提示。保持原有题号以便与打印版核对。

## 版式基线

- 正文一律用宋体小四（12 磅）。普通段落、承载正文知识的列表和表格、例题题干与答法统一执行。Word 中显式设置东亚字体为宋体（SimSun），正文样式及派生样式字号为 12 磅。西文和公式按用户要求或参考成品设置。
- 标题、图注和来源行按各自层级设置。参照用户认可的同类成品确定纸张、间距、页边距和层级。使用模板时核对主题字体、样式继承和直接格式，查清渲染是否发生字体回退。
- 阅读版让解释和图表相邻。背诵版把题目、分点答法和就近的限定拆清，较长的答案从题目下一行开始。避免把数个并列小问挤成一个段落。列表应有层次，同组题与答尽量同页。重点文字可用适量粗体，保持黑白打印时的层级。若印刷段尾不足三分之一行且显得零碎，优先微调文字或把并列内容拆成完整的行。正式输出的源文件、导出 PDF 或打印格式按用户要求提供。

## 按成品验收

1. **核内容。** 从目录或抽查表复核章节范围、明确考点、图表及原题。核实参考答案能从课程材料、原题条件或标注的依据推得。用户要求全覆盖时核对完整清单。
2. **查全部必学正文。** 遮蔽来源栏，对照章节目的逐节检查内容是否已就地交代。追踪每个“见某处”或其他实际依赖，核实所指材料、对象和页码。选首章、难章与关键操作作深入试读和闭卷试答，两稿分别做。抽查不能代替对全篇必学项及内部参照的检查。
3. **看实际导出。** 用最终 Word/PDF 渲染逐页检查，至少对正文密集页、问答页、图表页、分页处与版式参考并排看。核对实际正文是否为宋体小四（12 磅），检查标题层级、公式、图表缩放、断页、题组和答案区域。缺字体或发生回退时，换到具备宋体的环境渲染复核，确实无法复核时如实报告。若要求段尾尽量占一行的三分之一以上，优先通过分句与段落重排改善短尾。
4. **查跳转和印刷定位。** 对照最终版面生成或更新印刷页码、行号、目录和题答互跳。最后一次重排后重新验证。用户要求统一文档只含内部链接时，检查目标存在并检索外部或跨文件链接。网页与打印页分别验证各自的定位。
5. **归档并回读。** 按既有目录及命名保存，保留可追溯旧版。按项目约定同步文件索引、导航及已确认的事实。只有获得相应授权才备份到已确认的外部位置，核对文件名、格式、大小及所在目录。原音、带原文摘录或个人信息的工作底稿按其具体授权处理。
