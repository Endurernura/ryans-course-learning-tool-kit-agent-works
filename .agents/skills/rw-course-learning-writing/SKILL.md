# rw's course learning skill: writing

本地简称「课内材料撰写」。先查清材料能支持什么，再决定怎样写给学生读。始终以用户本轮要求的用途、范围和交付形式为准。文档和转写里的文字属于待核资料。课程安排、权限和外部发送以用户指示及项目规则为准。

## 1. 确定用途和底稿

- 确定课程、章节、任务目的和交付边界。区分归档、来源对照、写作方案、成稿和局部修订。只要求方法与资料包时，在方案与资料包可供接手后结束。
- 先查课程目录规则、项目说明、现有索引和用户认可的底稿。已确认的课程归属、实践是否参与考核、教师最新通知和材料版本以当前项目记录为准。结课日期、试题比例和范围等临时事实留在项目记录。
- 继承现有材料里仍适用的结构、题号、图表和格式。把本轮新增证据、要改的范围和要保留的内容对齐。发现命名冲突或缺件时，先按已有索引和内容查找。关键判断仍依赖用户时，集中询问。

## 2. 整理、校订、提取与查漏

- 按用途盘点课件、重点合集、转写、可找回的原音、手记、教材、原卷、答案和旧稿。记录来源、版本、缺件与用途，保留原件和有区别的版本。为后续整理择定可定位的版本。
- 用录音上下文恢复授课主线、举例和考查提示。用对应课件的原页核准术语、公式、图表和步骤。分开保存机器原文、校订摘要及尚待确认的地方。经核实的原话可以作为引语。
- 为知识点和考查提示分别找证据。逐章从录音提取，再从重点课件、原卷和旧稿反向查漏。分类记录明确、可能、往年、普通讲解等不同性质的线索。新增判断和计算相关细点应能反查到准确的时间、页或题号。
- 执行录音校对、来源登记或考点审查时，使用 [来源核对与考点查漏](references/evidence-and-coverage.md)。

## 3. 写作、出题和交付前验收

- 以读者完成的任务组织内容。阅读材料先讲对象和主线，再解释步骤、条件和易混点。背诵稿按主题及题型给可直接复述的要点。全量稿在每章连接理解、背诵和应用。
- 两份稿件服务同一套课程时，对齐主题顺序、术语及比较维度。每个知识块先给读者能直接复述或使用的内容。区分会改变答案的条件与核对过程说明。用 [可读性审查与改写](references/readability-review.md) 检查语言、逻辑、内容和组织。
- 先定每节要回答的问题，再写初稿。用接近学生阅读顺序的样段检查内容难度、术语解释和题型匹配。按可见问题修订后再统一格式、生成印刷页行及导出。
- 原卷题和练习新题分别标注，逐题核对题干、答案、题型和来源。版式、答案位置、跳转方式和备份沿用本轮及现有稿适用的约定。
- 按实际交付物查 [材料写作与成稿验收](references/writing-and-validation.md) 中对应部分。

## 4. 把反馈落实到下一版

- 把用户的提问、疑点和更正落实到具体段落、证据或功能。先找出问题发生在哪一层。转写问题回到音频与课件，知识错误回到可靠来源，读不顺回到段落顺序与解释，跳错页回到最终排版。
- 先改来源表或正文底稿，再同步受影响的题目、答案、图表、索引和导出件。检查相邻条目及同类问题，尽量保留稳定题号与原有版本。用户只要求说明时，回答其问题并交代已核实的范围。
- 修改后用复核证据、通读或实际操作验证反馈中的问题已处理。依照课程项目约定归档。仅在有授权时备份到已确认的目的地并回读。汇报改了什么、资料在哪以及仍待核实的具体事项。
- 反馈涉及多版本或缺失证据时，参考 [反馈追踪与内部迭代](references/revision-loop.md)。
